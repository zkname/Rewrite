# 来源与归属

本版本重新实现 Loon 网页 Cookie 捕获与手动登录校验，运行脚本不包含 wskey 换取、
genToken、App 签名、MD5、Base64 或第三方算法库，也没有运行时依赖下载。
复用的是前一版本的凭据校验、脱敏、存储隔离与 Loon 适配设计。

此前 App 捕获与签名的来源记录保留在 Git 历史
`5c57b205a102ce52b21beb932a6bbf62ce70da42` 的本目录中。
该历史实现参考 `FoKit/Scripts`、`zkname/Rewrite` 和 `z1988com/jd_scripts`，其原归属不变；
不因本次重写而将上游代码重新授予许可证。完整原始审计快照仍保留在本地独立审计目录。

保留根文件名 `get_jd_wskey.js` 与两个插件路径用于订阅兼容；这些名称不表示本版继续读取 wskey。
本版仅处理用户自己通过京东官方网站正常登录得到的 Cookie；真实手机与京东接口兼容性仍须实测。
