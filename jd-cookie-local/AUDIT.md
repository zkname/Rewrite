# 网页捕获版复核

范围：core、runner、adapter、生成的根脚本、两版 Loon 插件及 BoxJs 配置。
原 App 实现完整保留在 Git 历史；本版移除相关运行代码和签名测试工具，未改动独立任务项目。

只读端点核对：无凭据访问 `https://home.m.jd.com/myJd/home.action` 得到 302，Location 为
`https://my.m.jd.com/index.html?sceneval=2&sourceType=home_m`；无凭据访问固定登录校验接口得到
HTTP 200 / `retcode=1001`（未登录）。这只证明公开端点响应，不能代替带账号验收。

已确认的实现与边界：

- 网页只捕获 `m.jd.com`、`home.m.jd.com`、`my.m.jd.com` 的 HTTPS 请求头，原请求原样放行。
  不拦截登录正文，不读取密码，不读取响应中的远程代码，也不监听 App 后台域名。
- 每次只提取该请求内完整的 pt_key/pt_pin；无关 Cookie 字段不阻断捕获，重复冲突、非法值、
  控制字符、过大请求头和非白名单 URL 均拒绝，不跨请求补齐账号信息。
- 捕获与状态查询无主动 HTTP 调用。暂存只写手机；显示明确成功/缺失状态，对同类自动提示一分钟去重。
  手动状态不去重。所有通知和可见状态使用固定代码及脱敏账号，不包含原始请求、响应或错误详情。
- 暂存十五分钟内可校验，过期在手动操作时清除。旧 wskey 缓存不读取；已验证列表保留兼容结构。
- 只有手动校验向 `me-api.jd.com` 固定 HTTPS 地址发送规范化 Cookie；没有第三方接收方。
  TLS 校验开启，自动重定向和自动 Cookie jar 关闭；数据只按 JSON 解析。
- retcode 明确成功、可用身份字段一致后才更新已验证列表。校验期间账号变化时丢弃旧结果；
  失败不自动重试。协作锁与一分钟冷却限制重复请求。
- 运行代码不含签名、远程算法、动态代码执行、系统命令、外部推送、自动发布或自动更新。

验证：网页测试覆盖 URL 冒充、三个域名、Cookie 缺失/部分/冲突、中文编码、账号隔离、
通知去重与手动状态、存储失败、过期边界、重复校验、并发切换、登录失败、限流、重定向、超时、TLS 错误、
原请求不变、结束一次、无凭据日志，以及生成的新版/旧版插件均匹配同一白名单且固定脚本版本。
本地与固定青龙镜像的断网容器均为 51/51 项通过。容器使用非 root UID 65534、只读根目录、
network=none、全部能力丢弃、no-new-privileges，无宿主挂载；11 个文件哈希校验通过，监测 events=[]。
容器详情见 isolation-report.json，逐条记录在 test/isolation.tap。本地证据目录为
`.local/jd-loon-web.ejD9sq/`，可用 `node jd-cookie-local/tools/record-isolation.mjs .local/jd-loon-web.ejD9sq/ 51` 复核。

未完成与限制：

- Safari/Loon 真机抓取、真实账号登录校验及任务项目京豆查询仍未验收。不能根据模拟测试声称真实可用。
- 实际网页若不携带 pt_key/pt_pin，明确报告 WEB_INCOMPLETE；不会把其他类型凭据伪装成可用 Cookie。
- Loon 本地存储不是加密保险箱；BoxJs 的展示与备份由客户端控制。
- Loon 存储没有跨进程原子事务；同步更新与 nonce/账号复查可以防止已覆盖的并发，但不能承诺原子提交。
- 接口返回大小在回调后限制，不能限制 Loon 接收数据前的缓冲。
- 抓到的 Cookie 可能由服务端随时撤销；已验证状态只代表当次结果。

此版经用户授权发布到同一测试分支，订阅路径保持不变；main 和生产部署保持原状态。
