# App WSKEY 抓取复核

本次恢复抓取入口，功能范围仅限捕获、查看状态、清除暂存。不实现续期、换取 Cookie 或青龙上传。
未使用真实凭据进行测试；抓取是否适配当前手机 App、wskey 是否有效均尚未确认。

已确认：本地 26/26 合成测试通过，同一脚本在固定青龙镜像的断网容器中 26/26 通过。
容器非 root、只读根目录、无宿主 bind 挂载、全部 capability 移除、禁止提权。监测到的网络、进程、
文件写入禁用能力调用为零，10 个测试包文件哈希一致。摘要与日志见 isolation-report.json、test/isolation.tap。
静态 AST 检查发现数为零；该检查只作为人工源码复核的补充，不能证明所有运行环境安全。

已复核的数据路径：仅接受两个精确 App 域名的 HTTPS 请求，在单个请求的 Cookie 头中提取 wskey/pin。
值只写 `jdAppWskeyCaptureV1`；观察记录、状态和通知不包含凭据或账号原文。无 console、HTTP 客户端、
动态执行、配置中的命令、外部算法或运行依赖。响应数据不在工具功能范围内。

已覆盖：缺少头/字段、Cookie 多种表示、Base64 padding、中文账号、冲突重复值、长度和控制字符、
主机名伪装、账号切换、缺 pin 不合并、反复触发提示限流、凭据轮换、时间回退、十五分钟边界、
存储失败/异常、本地旧数据损坏、通知异常、清理与旧网页数据隔离、结束回调只执行一次。
生成后的脚本在禁用网络/系统能力的 VM 中逐个场景运行，原请求保持不变。

默认监听范围由原来两个窄路径扩至同样的两个精确域名，兼容路径变化并提供请求观察结果。
未扩展至 `*.jd.com` 或支付、登录等其他域名。如果 App 已不通过这两个域名发送 wskey，
插件仍无法获得它，应根据实测请求排查，不将“请求已触发”误报为“已抓到”。

限制：Loon 本地存储没有跨执行事务保证，最后一次成功写入的完整记录保留；不拼接不同记录，
但高并发下不保证按抓包时间排序。暂存过期仅在下次执行时清理，BoxJs 本身不会触发清理。
本地存储不承诺加密。已捕获与有效凭据严格区分，所有记录的 identity 均为 unverified。

本次没有 GitHub 推送，没有生产部署，也没有更改原四项任务的验收结果或待核对写操作。
